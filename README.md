# 📚 Bookstore Web App – Metodologías y Desarrollos Web

This project was developed as part of the **“Metodologías y Desarrollos Web”** university course.  
It’s a full-stack bookstore application featuring authentication, state management, and a modern frontend stack.

## 🧭 Overview

The application allows users to browse books, manage their account, and simulate a basic shopping flow. It demonstrates the integration of a React frontend with a Node.js backend using Firebase and MongoDB.

## 🖥️ Frontend

- **React** + **Vite** for fast development and optimized builds  
- **Redux** for global state management  
- Deployed on **Vercel**

## 🛠️ Backend

- **Node.js** server  
- **Firebase Authentication** for secure user management  
- **MongoDB Atlas** as the database

## ✨ Features

- User authentication (sign up / login)  
- Product listing and browsing  
- Basic shopping flow  
- State persisted through Redux  
- Responsive design
